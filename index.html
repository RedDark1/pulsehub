Упаковка PulseHub в .EXE и .APK

Скачайте готовые исходные файлы проекта ниже. С их помощью вы можете за 2 минуты получить полноценный установщик .APK для Android или .EXE / .DMG для Windows и macOS.

🤖

Как собрать .APK для Android

2 способа: без программирования или через Capacitor

Способ 1: В 2 клика через PWABuilder (Без установки SDK)
  1. Загрузите файлы index.html, manifest.json и sw.js на любой бесплатный хостинг (GitHub Pages, Vercel или Netlify).
  2. Откройте сайт pwabuilder.com и вставьте ссылку на ваше приложение.
  3. Нажмите Package for Stores → Android и скачайте готовый подписанный .APK файл!
Способ 2: Локально через Capacitor
npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init PulseHub com.pulsehub.app --web-dir=.
npx cap add android && npx cap open android
💻

Как собрать .EXE для Windows / macOS

Мгновенная упаковка через Electron или браузер

Способ 1: Мгновенно через Edge / Chrome (Без консоли)

Нажмите кнопку «Установить приложение» в шапке этой страницы. Windows/macOS создаст ярлык в меню «Пуск» / Launchpad и откроет PulseHub как нативную программу.

Способ 2: Автономный .EXE через Electron Forge
npm init -y && npm i -D electron electron-builder
# Положите index.html в папку проекта и запустите сборку:
npx electron-builder --win --x64
